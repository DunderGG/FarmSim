# Security policy

Project Vestige is a single-player game in early development. There are no servers or accounts, but security still matters for things like save files and, later, mods: a crafted file should never be able to crash the game in a way that runs code or touches files outside the game's folders.

## Supported versions

Only the latest commit on `main` is supported. There are no released builds yet.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately instead:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** and describe the problem, how to reproduce it, and what an attacker could do with it.

You'll get a reply within a week. Once the problem is fixed, you'll be credited in [CREDITS.md](CREDITS.md) unless you'd rather not be.

For ordinary bugs, open a normal issue; see [CONTRIBUTING.md](CONTRIBUTING.md#8-ideas-bugs-and-feedback).
